## **Q1. Workspace Architecture Map**

1.  **VS Code :**
 Used for writing and editing Python code, organizing project folders, creating the README.md, running terminal commands, and initializing the Git repository.

2.  **Local Jupyter :**
Used to run and test notebooks on my computer, load datasets, verify the code, and generate the required outputs before submission.

3. **Google Colab:**
Used to execute notebooks in the cloud, save work on Google Drive, and create shareable notebook links for the practical tasks.    

3.  **GitHub Repository :**
Used to store and manage the complete project, including notebooks, datasets, screenshots, and the README.md. It also keeps track of all project    

4.  **Google Drive Submission Folder:**
  Used to upload the scanned handwritten answer PDF and any additional evidence files. The folder will have view access so it can be accessed during evaluation.

5.  **Final Portal Submission:**
   Used as the final submission platform where I will provide all the required links (GitHub, Colab, and Google Drive) along with a short explanation for each.
